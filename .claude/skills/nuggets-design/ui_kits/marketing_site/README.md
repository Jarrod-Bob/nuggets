# UI kit — nuggets landing page

**Speculative.** There is no marketing site in the repo and none is specified.
This exists because you asked for the surface; treat it as a proposal, not a
recreation.

**All the copy is lifted from the repo's own README**, lightly reordered and
switched from first to second person. Nothing here claims a feature the MVP
doesn't have, and the page states plainly that the project is designed but not
built — the "Designed, not built yet" badge in the nav and the closing section
both say so.

## Sections

1. **Nav** — wordmark, honest status badge, link to the repo.
2. **Hero** — the promise in one line, over the breading texture, with the nugget trio.
3. **Why** — the Telegram problem, in the README's own words, next to three live idea
   cards. "Draw another" moves the bite between them, which is the random draw in
   miniature.
4. **What it does** — the five scope bullets from the README, one card each.
5. **Zero cost** — the stack table, on the system's one ink section.
6. **Close** — a bitten nugget and the "nothing to install yet" note.

## Notes

- Only one golden and one ink section on the page, per the visual foundations.
- The breading texture appears once, behind the hero, never behind body copy.
- The bite mark is used exactly twice, both times meaning "this one's been eaten".
