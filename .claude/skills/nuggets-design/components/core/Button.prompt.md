Pill action button in display type with a chunky crust edge — use for every committed action; use `ghost` for tertiary/inline actions.

```jsx
<Button variant="primary" size="md" onClick={save}>Drop a nugget</Button>
```

Variants: `primary` (golden, the default CTA), `danger` (ketchup, destructive only), `secondary` (cream with an ink outline), `ghost` (no edge, no fill — toolbars and cancel actions). Sizes `sm|md|lg`. Ghost is the only variant without the crust edge and press-drop.
