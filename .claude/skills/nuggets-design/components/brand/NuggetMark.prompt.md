The nugget illustration set — a brand motif, not a logo (Nuggets has no logo yet).

```jsx
<NuggetMark variant="trio" size={120} />
```

Variants: `single`, `alt` (rotated), `trio` (hero), `bucket` (collections), `dip` (accent). Decorative only — always keep a text label nearby.

`bitten` swaps in the eaten version (`single` and `trio` only). Use it where something has been *used up or acted on* — the empty trash, a drawn challenge, the end of a marketing page. Never on a first-run empty state, where nothing has been eaten yet.
