# Curry

The curry-dip study, as SVG with the Newsprint colours baked in (curry `#956a0a`, curry-gloss `#d9a53a`, ink `#141210`). They are reference drawings for the `NuggetCard` curry corner, which draws the same thing itself from the card's own outline. Use them in specs and slides, not in the app.

- `curry-card-base.svg`: card shape 0 with nothing on it.
- `curry-rest.svg`: a named nugget at rest, a dab on the top-right corner with two drips.
- `curry-spread.svg`: mid-pour, two-thirds across.
- `curry-full.svg`: settled, the card covered and drips hanging off the bottom edge.

Regenerate them with `node design/comic-strip/src/curry.js`.
