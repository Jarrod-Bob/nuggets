# Illustrations

The finished drawings from the nuggets app, as SVG with the Newsprint colours baked in (ink `#141210`, nugget `#ffb21e`, tomato `#e8452c`, mayo `#fff3d6`, toast `#f2c9a8`). Use them as `<img>`; they do not follow token changes.

- `bucket.svg`: the striped bucket piled with nuggets. The bucket page's feature, on a `Burst`. Its label panel is left blank: set "NUGGETS" in `sfx` tomato and a `label` line over it.
- `hero-nugget.svg`: the single large nugget for a nugget's own page, on a `Burst`.
- `fig1-nugget.svg`: the small sketch beside a "FIG. 1" caption.
- `burst.svg`: the sunburst on its own, for places that cannot run the `Burst` component.
- `gingham.svg`: the tray's red gingham, as a 40px pattern. Put it behind the tray's liner panel.
